# Java Essentials

## Plataforma de laboratorios

Te damos la bienvenida a la **plataforma de laboratorios** del curso **Java Essentials [JAVA_ESS]**. Aquí reforzarás los fundamentos de Java mediante ejercicios de estructuras de control, arreglos, ciclos y programación orientada a objetos, hasta desarrollar y ampliar una aplicación de banca electrónica.

## Lista de laboratorios

Cada uno de estos laboratorios está diseñado para ofrecerte una experiencia práctica. Haz clic en los enlaces para comenzar.

## Capítulo 3

### [Práctica: Repaso estructuras de control](Capitulo3.md)

- **Descripción**: Desarrolla un menú de consola e integra ejercicios de cálculo de IMC, tarifas de peaje, validación de mayoría de edad, una historia interactiva y cotización de seguros. Aplica estructuras `if-else`, `switch` y el operador ternario para resolver condiciones y validar las opciones del usuario.
- ⏱️ **Duración estimada**: 30 min.

## Capítulo 4

### [Práctica: Repaso arreglos y ciclos](Capitulo4.md)

- **Descripción**: Amplía el menú con ejercicios de vacaciones por antigüedad, manejo de `ArrayList`, números primos y factoriales. Utiliza arreglos y ciclos para controlar espacios de estacionamiento, identificar palíndromos y anagramas, y encontrar la mejor combinación de compra y venta de una acción.
- ⏱️ **Duración estimada**: 50 min.

## Capítulo 7

### [Práctica: Repaso POO: Banca Electronica](Capitulo7.md)

- **Descripción**: Construye el proyecto `BancaElectronica` con clases para cuentas y cuentahabientes, depósitos, retiros y administración de cuentas. Aplica encapsulamiento, herencia, sobrescritura y clases abstractas para implementar cuentas de cheques e inversión con reglas específicas de operación.
- ⏱️ **Duración estimada**: 60 min.

## Capítulo 10

### [Práctica: Repaso POO 2: Banca Electronica extendida](Capitulo10.md)

- **Descripción**: Extiende el proyecto de banca electrónica con una clase `Banco` y una interfaz para administrar clientes. Integra `List`, `LocalDate` y el cálculo de vigencia de las cuentas, y crea excepciones personalizadas para controlar retiros con saldo insuficiente y operaciones de inversión fuera del plazo permitido.
- ⏱️ **Duración estimada**: 40 min.
